# Fitness for Everybody

Photo-first nutrition tracking MVP based on `Fitness_for_Everybody_PRD.md`.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Vercel-ready project structure

## MVP Behavior

The first version uses mock data and local storage:

- Onboarding profile and goal setup
- BMR and nutrition target estimates
- Training day / rest day toggle
- Multi-image food upload UI
- Mock food recognition and editable nutrition values
- Daily nutrition dashboard
- Meal recommendations and protein powder options
- Random "shake" recommendation

Real Claude Vision, nutrition database, Supabase auth, and Supabase persistence are intentionally left for later integration.

## Commands

```bash
npm install
npm run dev
npm run build
```
